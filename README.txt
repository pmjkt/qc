QC as an installable app (works offline once installed)

1. Upload the CONTENTS of this folder (index.html, manifest.webmanifest, sw.js, icons/) to any HTTPS host:
   - Netlify Drop (app.netlify.com/drop): drag the folder in, you get a link.
   - or GitHub Pages / Cloudflare Pages.
2. Open the link in Chrome on your phone.
3. Menu (three dots) > Install app (or Add to Home screen).

It then opens full screen from your home screen and keeps working with no internet.
Your settings and photos stay on the phone.
